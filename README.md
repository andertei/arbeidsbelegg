# Arbeidsbelegg

Dette repoet inneholder en Excel-mal for planlegging av arbeidsbelegg og faktureringsgrad per kvartal. Malen dekker fem år, fra 2027 til 2031, og er laget for å fylles ut med egne prosjekter og kapasitetsforutsetninger.

[Åpne eller last ned Excel-malen](Arbeidsbelegg.xlsx)

## Innhold

- **Oversikt:** viser tilgjengelig kapasitet, planlagte timer, samlet belastning, fakturerbare timer og faktureringsgrad per kvartal. Overbooking markeres tydelig.
- **Kapasitet:** angi timer per arbeidsuke og planlagt ferie eller annet fravær for hvert kvartal. Kapasiteten beregnes etter at fravær og helger er trukket fra.
- **Planlegging:** legg inn én linje per prosjekt og kvartal, med planlagt andel av tilgjengelig arbeidstid.
- **Prosjekter:** registrer prosjektnummer, prosjektnavn og om prosjektet er fakturerbart.
- **Helligdager:** inneholder norske helligdager for planperioden. Listen kan tilpasses lokale fridager og egne avtaler.

## Kom i gang

1. Fyll inn kapasitet og fravær per kvartal i **Kapasitet**.
2. Registrer prosjektene i **Prosjekter**, og velg Ja eller Nei for fakturerbar status.
3. Legg inn prosjekt, år, kvartal og planlagt prosent i **Planlegging**.
4. Følg med på belastning og faktureringsgrad i **Oversikt**.

Prosjektprosenten er andelen av tilgjengelige timer etter fravær. Faktureringsgrad beregnes som planlagte fakturerbare timer delt på tilgjengelige timer.
